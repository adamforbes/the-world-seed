# The World Seed

The rules for *The World Seed*, a collaborative worldbuilding game for session 0, as a small website.

Open `index.html` in a browser to read them.

The HTML pages are the source of truth for the rules. They were migrated on 2026-10-20 from the Markdown files in Google Drive at `My Drive/DnD/ProceduralWorldBuilder/rules/`, which are now an archive.

See `CLAUDE.md` for how the pages are organized and how to edit them.
